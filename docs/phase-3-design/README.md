# Phase 3 Design Output Directory

This directory contains all artifacts generated by the Phase 3 UI/UX Design Pipeline.

## File Registry

| File | Created By | Format | Order |
|------|-----------|--------|-------|
| `design_spec.json` | AI agents (Phase 3.2) | JSON | 1st — plugin input |
| `figma_file.md` | Plugin completion summary (Phase 3.3) | JSON | 2nd — plugin output |
| `component_library.md` | mcp-figma `figma_get_components` (Phase 3.4) | Markdown | 3rd |
| `design_tokens.dtcg.json` | mcp-figma `figma_extract_design_tokens` (Phase 3.4) | DTCG JSON | 4th |
| `tokens_css.css` | mcp-figma `generate_css_tokens` (Phase 3.4) | CSS | 5th |
| `tokens_android.xml` | mcp-figma `generate_android_tokens` (Phase 3.4) | Android XML | 6th |
| `tokens_ios.swift` | mcp-figma `generate_ios_tokens` (Phase 3.4) | Swift | 7th |
| `accessibility_report.json` | mcp-figma `compute_apca_contrast` + `compute_wcag_contrast` (Phase 3.4) | JSON | 8th |
| `screen_inventory.md` | Agent-assembled from figma_file.md + design_spec.json (Phase 3.4) | Markdown | 9th |
| `design_verdict.json` | consensus-agent (Phase 3.6) | JSON | 10th — final gate |

## Key Conventions
- All files are auto-generated — do not edit manually
- `design_spec.json` is the single source of truth for what the plugin creates
- `figma_file.md` contains real Figma node IDs — required for all mcp-figma tool calls
- `design_verdict.json` must contain `"verdict": "DESIGN APPROVED"` before Phase B begins
